# Background Sky

This page describes ALMASim's additive background sky.

## Purpose

ALMASim can add an astrophysical background sky to the model cube before the interferometric simulation.

This is separate from thermal or atmospheric noise (see [Noise](noise.md)) and from the [serendipitous sources](skymodels.md#serendipitous-sources).

The background is generated by `generate_background_cube()` in [`services/simulation/background.py`](../src/almasim/services/simulation/background.py).

## Default Behavior

The default background mode is `none`: no background sky is added.

## Background Modes

### `blank_field_dsfg`

Adds a sparse field of faint dusty star-forming galaxies, each in one pixel with a steep rising spectrum (flux proportional to ν^α, α between 2.5 and 4).

This approximates blank-field extragalactic confusion at ALMA frequencies. The number of galaxies scales with the field's area and the level.

### `dusty_diffuse`

Adds a smooth, positive, low-spatial-frequency dusty field with a ν^3 spectrum.

This is a first approximation to diffuse mm/sub-mm background structure.

### `combined`

Adds both of the above.

## Controls

`SimulationParams` exposes:

- `background_mode`: `none` (the default), `blank_field_dsfg`, `dusty_diffuse` or `combined`
- `background_level`: scales the background's brightness, relative to the observation's continuum sensitivity (default 1.0; 0 adds nothing)
- `background_seed`: makes the background reproducible

Without `background_seed`, the background is drawn from the run's `seed` (see [Reproducibility](simulation.md#reproducibility)).

On the command line, `almasim simulation` takes `--background-mode`, `--background-level` (default 1) and `--background-seed` (default: the run's seed). A `--background-level` above 0 without a `--background-mode` is refused, since it would add nothing.

## Physical Intent

The background is a pragmatic model for ALMA-band simulations:

- faint unresolved dusty galaxies
- diffuse dusty structure with smooth spectral dependence

It is not a full cosmological sky model.

## Outputs

When a background is generated, it is added to the model cube.

Every run, with or without a background:

- records the mode, level, seed and total injected flux (`background_total_flux_jy`) in the run metadata
- returns the background as `background_cube` in its results
- exports it as `background-cube_<idx>` when outputs are persisted (all zeros without a background)

## Scope Notes

This is an astrophysical background, not:

- atmospheric emission
- calibration error
- correlator noise

Those belong to the [noise model](noise_models.md).
