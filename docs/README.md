# ALMASim Documentation

This directory contains focused markdown documentation for the main ALMASim subsystems.
The published site ([astromadiv.github.io/ALMASim](https://astromadiv.github.io/ALMASim/))
is built from these pages with Sphinx (`docs/source/`), in the order listed here.

## Scope

These pages describe the current codebase, not an aspirational API. They focus on what ALMASim does today and how the main pieces fit together.
